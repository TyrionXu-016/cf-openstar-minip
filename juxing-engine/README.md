## 🚀 快速上手

### 1. 开通腾讯云服务

1. 注册腾讯云账号并完成企业认证
2. 开通以下服务：
   - **云开发**：微信公众平台 → 云开发控制台
   - **混元大模型**：腾讯云控制台 → 混元 → API Key
   - **OCR**：腾讯云控制台 → 云 API 密钥

3. 获取凭证并填写到云函数中：
   - `TC_SECRET_ID`
   - `TC_SECRET_KEY`
   - 环境 ID

### 2. 导入项目

1. 打开微信开发者工具
2. 导入项目，选择 `juxing-engine` 目录
3. 填写 AppID
4. 勾选"使用云开发"

### 3. 部署云函数

1. 右键点击 `cloudfunctions` 文件夹，选择"上传并部署"
2. 依次部署4个云函数
3. 确保云函数已正确安装依赖

### 4. 修改配置

1. `miniprogram/app.js`：填写云开发环境 ID
2. `cloudfunctions/*/index.js`：填写腾讯云 API 密钥

## 云开发与联调检查清单

1. **小程序环境**：在微信开发者工具中勾选「云开发」；将 `miniprogram/app.js` 里 `wx.cloud.init` 的 `env` 改为你自己的云环境 ID（勿把生产密钥写进公开仓库）。
2. **云函数部署**：在 `cloudfunctions` 下对实际用到的函数（如 `aiQA`、`generateQuestion`、`gradeEssay`、`ocrRecognize`、`getPositions`、`initPositions`）执行「上传并部署：云端安装依赖」，并在云开发控制台确认无启动报错。
3. **腾讯云凭证**：在云函数环境变量或控制台配置中注入混元 / OCR 所需的 `SecretId`、`SecretKey`（或当前项目采用的 VC3 等安全注入方式），与官方文档中的调用区域、模型名保持一致。
4. **联调顺序建议**：先单独在云控制台测试云函数 → 再在模拟器走通「AI 出题 / 申论批改 / 拍题识别 / 选岗拉全量 / AI 答疑」→ 最后真机验证网络与权限。
5. **静默降级开关**：学习设置页「云端失败时静默降级」写入本地键 `settings_quiet_cloud_fallback`；开启后，AI 答疑等走本地降级时不再弹出 Toast（仍可在控制台看报错日志）。
6. **选岗云端提示**：从学员信息页带参进入选岗时，若本地岗位条数小于预期总量且未标记过 `job_match_cloud_prompt_done`，会弹窗询问是否拉取云端全量；需重新测试时可清除该项本地存储。
