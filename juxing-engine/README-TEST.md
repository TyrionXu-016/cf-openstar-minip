# 🚀 聚星引擎小程序 - 测试号配置指南

## 📋 测试号申请步骤

### 1. 获取微信小程序 AppID（测试号）

1. 打开微信开发者工具
2. 点击「新建项目」
3. 在 AppID 输入框下方，点击「测试号」按钮
4. 系统会自动生成一个测试用 AppID
5. 复制这个 AppID

### 2. 更新项目配置

在 `project.config.json` 中更新 AppID：

```json
{
  "appid": "你的测试号AppID",
  "projectname": "juxing-engine-test",
  "description": "聚星引擎 - 公考AI学习助手",
  ...
}
```

### 3. 打开项目

1. 打开微信开发者工具
2. 选择「导入项目」
3. 项目目录：选择 `juxing-engine/miniprogram`
4. AppID：粘贴你的测试号
5. 项目名称：聚星引擎-测试

## ✨ 已添加的功能

### 🆕 新增「学员测评」功能

**入口位置**：首页 → AI智能功能 → 学员测评

**功能说明**：
- 学员信息录入（姓名、电话）
- 题目数量选择：40道（快速）/ 60道（标准）/ 120道（全面）
- 难度等级选择：🌱简单 / ⚖️正常 / 🔥较难
- 随机生成测评题目

## 🔧 快速测试

1. 导入项目后，直接点击「编译」
2. 在模拟器中查看首页
